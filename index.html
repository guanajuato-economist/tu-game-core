    Definitions

    The core is the set of allocations x = (xA, xB, xC) with

    xA+xB+xC = v(N) (efficiency)
    xi ≥ v({i}) for each player i
    xi+xj ≥ v({i,j}) for each pair

    Each inequality is a half-space bounded by a plane; on the efficiency plane each boundary becomes a line. The core is the intersection of the six half-planes with the efficiency plane.

    The nucleolus is the imputation that lexicographically minimises the coalitions' excesses e(S,x) = v(S) − x(S), largest first. It always lies in the core when the core is non-empty.
